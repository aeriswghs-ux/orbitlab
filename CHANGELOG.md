# Changelog

## 0.1.0 — 2026-11-25

- Created a separate local OrbitLab educational project, independent of AeroLab.
- Added a guarded two-body Earth orbit engine, circular/elliptical presets, perigee-speed reconstruction, and explicitly labeled inclination projection.
- Added play/pause, reset, stepping, playback rate, equal-time sectors, numerical text readouts, baseline comparison, and CSV measurements.
- Added five static lessons with worked examples, experiments, conceptual quizzes, and feedback.
- Adapted the user's portfolio fieldbook palette and visual hierarchy to responsive semantic pages.
- Added configurable canonical URLs, page metadata, social cards, lesson structured data, sitemap, robots and 404 page.
- Added physics and site verification, independent RK4 comparison, references, design rationale and deployment instructions.
- Default output is a local noindex preview; no publication, remote repository, or live public site is claimed.
